## Question and authorized scope

Does one natural `/codebook` request, declared by the editor's own agent from source alone, pass on its first admitted run in Copilot Chat and in Cursor Agent on the delivered source, and can the learner save it and reopen it as a learning replay? If not, what stops it, and does it pass once that is fixed?

Why now: it is the product's defining experience (PRODUCT_GOAL, "Defining live-to-learning experience"; AC-LIVE, AC-SAVE). Cycle 0044 changed the live-run code the most (object inspections, the anchor index refusal, a stop on a line without a mapped position, the binding and pause rules) without one chat run (its row T-5). Every later step of the route, the nine-project Stage 1, starts with this request shape.
